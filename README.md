# Obsidian Core

A clear Obsidian structure with reusable note templates.

## Start

1. Clone or download this repository.
2. Open its root folder as a vault in Obsidian.
3. Set `Templates/` as the Templates-plugin folder if you use that core plugin.
4. Capture a note in [00 Inbox](00%20Inbox/README.md), then move it when its purpose is clear.

## Structure

- [00 Inbox](00%20Inbox/README.md) for uncategorised capture.
- [10 Projects](10%20Projects/README.md) for finite outcomes.
- [20 Areas](20%20Areas/README.md) for ongoing responsibilities.
- [30 Resources](30%20Resources/README.md) for reference material.
- [40 Archive](40%20Archive/README.md) for inactive material.
- [Templates](Templates/Daily%20Note.md) for reusable note starting points.

## Privacy

The vault content intentionally contains no app configuration, plugins, attachments, personal notes, credentials, contact data, or external service references. Keep local app configuration private.
