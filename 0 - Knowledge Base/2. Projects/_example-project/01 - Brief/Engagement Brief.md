# Engagement Brief

Northwind is an invented company. This folder shows the note conventions a real project
would follow, using material that was made up for the purpose.

## Problem

Dispatch rebuilds the same weekly plan by hand because route changes arrive by phone and
never reach the planning sheet.

## Outcome

A route change is recorded once and is visible to planning the same day.

## Out of scope

Billing, payroll, and anything touching the vehicles themselves.

## Open questions

- Who owns the planning sheet when the dispatcher is away?
- Does a change need approval, or only a record?
