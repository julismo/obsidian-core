# Intake Procedure

A procedure note is written so somebody else can follow it without asking. Invented
example.

## When to use

A route change arrives from anyone outside the planning team.

## Steps

1. Write the change in [[_example-project/04 - Triage/Triage Log]] before doing anything
   else, even if it turns out to be nothing.
2. Name one owner. If nobody will own it, record that and stop.
3. Decide same day or next working day: act, defer with a date, or decline with a reason.
4. Tell whoever raised it what was decided.

## Failure modes seen so far

- The change is fixed directly and never written down, so the next person repeats it.
- Two people act on the same change because neither claimed it.
