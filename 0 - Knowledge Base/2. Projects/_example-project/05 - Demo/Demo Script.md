# Demo Script

Written before the demo, not after. If a step cannot be written down in advance, it is not
ready to show. Invented example.

## Setup

Start from the state the dispatcher sees on a normal Monday, not from an empty screen.

## The one story

A route change arrives mid morning. Show it recorded, owned, and visible to planning
before lunch. Nothing else is shown, even if asked.

## Steps

1. Open the plan as the dispatcher.
2. Record the incoming change, naming an owner.
3. Switch to the planning view and show the same change already there.

## What can go wrong

- Being tempted into a second story and running out of time.
- Showing an empty screen first, which makes the tool look like more work.
