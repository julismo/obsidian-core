# Status tags

- `#status/inbox` means the note needs a decision.
- `#status/active` means the note is being used now.
- `#status/done` means the note is complete but still useful.

Use `#kind/knowledge`, `#kind/rough-note`, `#kind/source`, and `#kind/project` to describe
what a note is.

The vocabulary is deliberately short. A tag earns its place by being worth filtering on
later, not by describing the note accurately. When in doubt, write it in the note instead.
